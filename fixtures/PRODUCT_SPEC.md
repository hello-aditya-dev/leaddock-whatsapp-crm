# LeadDock Product Specification

## Product
LeadDock — WhatsApp Web CRM

## Positioning
Turn WhatsApp Web into a lightweight sales CRM.

## Commercial Tiers
- Commercial: $59
- Agency: $99

## Core Features
- lead statuses
- custom tags
- contact notes
- custom fields
- quick replies
- slash shortcuts
- template variables
- follow-ups
- dashboard
- pipeline
- search
- CSV import/export
- JSON backup/restore
- privacy mode
- command palette
- demo mode
- white-label configuration

## Constraints
- Manifest V3
- Vanilla JavaScript
- chrome.storage.local
- No backend by default
- No bulk messaging
- No auto-send
- No unsolicited outreach automation
- Independent product; no WhatsApp/Meta affiliation claim
